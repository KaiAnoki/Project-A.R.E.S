# Security policy

A.R.E.S. is intended for local, single-user operation. It does not include login controls for exposure to a public network.

- Keep the server bound to `127.0.0.1`.
- Do not commit `.env` files or the SQLite database.
- Leave private overrides disabled unless you trust every local override file.
- Treat stored chats and memories as private data.
- Report repository security problems through GitHub's private security advisory feature.
