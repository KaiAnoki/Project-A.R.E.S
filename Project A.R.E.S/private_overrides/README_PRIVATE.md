Place your private ARES extensions here. This folder is ignored by git.

Suggested files:
- private_overrides/private_optimizer.py
- private_overrides/private_prompts.py
- private_overrides/private_memory.py
- private_overrides/private_routes.py

The public GitHub version of ARES will continue to work without these files.
If present, the runtime can import and use them to override the public defaults.
